# Reportes de auditoría

Un archivo por revisión: `AAAA-MM-DD-<tarea>.md`, con este contenido:

- tarea y RF;
- archivos revisados;
- resultado (**aprobado** / **observaciones** / **rechazado**);
- hallazgos ordenados por severidad;
- tests añadidos;
- verificación de las reglas de dependencia y de RLS.
