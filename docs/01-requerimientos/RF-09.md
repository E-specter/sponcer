# RF-09 — Clasificación automática

**Prioridad MVP:** imprescindible  
**Módulos:** [clasificacion](../04-modulos/clasificacion.md)

## Descripción

Cada perfil se clasifica a partir de los datos ingeridos y declarados.

## Criterios de aceptación

- Se calcula nicho principal y secundarios con confianza, tier de seguidores, engagement y embedding.
- Lo declarado prevalece sobre lo inferido.
- Se reclasifica al cambiar datos ingeridos o declarados. Detalle en [ADR-003](../02-arquitectura/adr/ADR-003-clasificacion-matching.md).
