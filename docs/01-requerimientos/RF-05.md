# RF-05 — Datos declarados estandarizados

**Prioridad MVP:** imprescindible  
**Módulos:** [perfiles](../04-modulos/perfiles.md)

## Descripción

El usuario completa lo que no se puede rastrear mediante formularios con estructura fija.

## Criterios de aceptación

- Los campos usan catálogos/enums versionados (nichos, sectores, formatos, objetivos) en `contracts/`.
- Texto libre solo donde no hay alternativa (p. ej. descripción corta, máx. 280 caracteres).
- Validación idéntica en frontend y backend (mismo esquema zod).
