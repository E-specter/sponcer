# RF-10 — Descubrimiento y match por tarjetas

**Prioridad MVP:** imprescindible  
**Módulos:** [matching](../04-modulos/matching.md)

## Descripción

Feed de tarjetas con filtros específicos para afinar el match.

## Criterios de aceptación

- Las marcas ven creadores; los creadores ven marcas.
- Ordenado por puntaje de compatibilidad; filtros combinables (nicho, tier, engagement, precio/presupuesto).
- Acciones por tarjeta: me interesa / descartar / ver ficha / solicitar cotización.
- Match = interés mutuo; abre el chat.
