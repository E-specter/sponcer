# RF-04 — Multiperfil

**Prioridad MVP:** imprescindible  
**Módulos:** [auth](../04-modulos/auth.md), [perfiles](../04-modulos/perfiles.md)

## Descripción

Una cuenta puede vincular varios perfiles de Instagram, cada uno verificado como propio.

## Criterios de aceptación

- Cada perfil vinculado pasa por [RF-02](RF-02.md).
- El rol (creador o marca) pertenece al perfil, no a la cuenta: una cuenta puede tener perfiles de ambos tipos.
- El usuario elige el perfil activo desde el panel.
