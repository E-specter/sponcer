# RF-13 — Chat

**Prioridad MVP:** deseable (primero en recortarse si hay retraso)  
**Módulos:** [chat](../04-modulos/chat.md)

## Descripción

Mensajería asíncrona en tiempo real entre las partes de un match.

## Criterios de aceptación

- Solo disponible entre perfiles con match mutuo.
- Mensajes persistidos; entrega en tiempo real vía Supabase Realtime; envío por la core API.
- Historial paginado.
