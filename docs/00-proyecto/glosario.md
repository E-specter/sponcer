# Glosario

| Término | Definición |
|---|---|
| Perfil | Ficha de una cuenta de Instagram dentro de Sponcer, con rol `creador` o `marca` |
| Ficha previa | Perfil generado desde datos públicos, todavía sin dueño (RF-01) |
| Reclamar | Proceso para vincular una ficha a un usuario, mediante verificación por código en la bio (RF-02) |
| Datos ingeridos | Datos obtenidos de Instagram. Son de solo lectura para el usuario |
| Datos declarados | Datos que completa el usuario con catálogos fijos (RF-05) |
| Snapshot | Copia fechada de los datos ingeridos de un perfil (`ig_snapshots`) |
| Tier | Rango de seguidores: nano, micro, mid, macro, mega |
| Engagement | Promedio de (likes + comentarios) dividido entre los seguidores, sobre los últimos posts |
| Interés | Acción unilateral sobre una tarjeta del feed |
| Match | Interés mutuo entre un perfil creador y un perfil marca. Habilita el chat |
| Cotización | Solicitud sobre un servicio del creador, con una máquina de estados |
| Slice | Módulo vertical del backend organizado como un hexágono |
| Adaptador mock | Implementación de un puerto con datos semilla (`contracts/fixtures`) |
